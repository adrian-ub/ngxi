## Icon Set Info

- Name: System UIcons
- Prefix: system-uicons
- Icons: 430
- License: Unlicense
- Author: Corey Ginnivan
- Website: https://github.com/CoreyGinnivan/system-uicons


## Installation

```sh
pnpm add @ngxi/system-uicons
```

## Usage

```ts
import { Component } from '@angular/core'
import { SystemUiconsBell } from '@ngxi/system-uicons'

@Component({
  imports: [SystemUiconsBell],
  template: `<svg systemUiconsBell></svg>`
})
export default class {}
```
