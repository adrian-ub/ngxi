## Icon Set Info

- Name: Font Awesome 5 Brands

- Icons: 460

- Author: Dave Gandy
- Website: https://github.com/FortAwesome/Font-Awesome


## Installation

```sh
pnpm add @ngxi/fa-brands
```

## Usage

```ts
import { Component } from '@angular/core'
import { FaBrandsAmazon } from '@ngxi/fa-brands'

@Component({
  imports: [FaBrandsAmazon],
  template: `<svg faBrandsAmazon></svg>`
})
export default class {}
```
